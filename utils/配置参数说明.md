# 目标追踪系统配置参数说明

## 概述

本系统现已支持运行时配置，您可以通过修改 `config.json` 文件来调整各种参数，**无需重新编译代码**。程序启动时会自动加载配置文件中的参数。

## 配置文件结构

配置文件 `config.json` 中的 `object_tracking` 节点包含了所有目标追踪相关的参数：

```json
{
  "object_tracking": {
    "yolo_detector": { ... },
    "bytetrack_tracker": { ... },
    "video_processing": { ... },
    "counting_module": { ... },
    "display": { ... },
    "performance": { ... },
    "location_report": { ... }
  }
}
```

## 详细参数说明

### 1. YOLO检测器配置 (`yolo_detector`)

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `model_path` | string | "./models/fil.plan" | TensorRT模型文件路径 |
| `gpu_id` | int | 0 | GPU设备ID（0表示第一块GPU） |
| `confidence_threshold` | float | 0.25 | 置信度阈值（0.0-1.0，越高越严格） |
| `nms_threshold` | float | 0.25 | NMS非极大值抑制阈值（0.0-1.0） |
| `num_classes` | int | 1 | 数据集类别数量 |

**使用建议：**
- 如果检测到太多误报，可以提高 `confidence_threshold`（如0.5）
- 如果漏检较多，可以降低 `confidence_threshold`（如0.15）
- 更换模型时，需要修改 `model_path` 和 `num_classes`

### 2. ByteTrack追踪器配置 (`bytetrack_tracker`)

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `frame_rate` | int | 25 | 视频帧率（fps，影响追踪缓冲区计算） |
| `track_buffer` | int | 30 | 追踪缓冲区大小（帧数，目标丢失后保持的帧数） |
| `use_reid` | bool | false | 是否启用ReID特征（提高准确性，降低速度） |
| `track_class` | int | 0 | 要追踪的目标类别ID |

**使用建议：**
- 如果目标经常丢失ID，可以增加 `track_buffer`（如50）
- 如果追踪性能不够，可以设置 `use_reid` 为 false

### 3. 视频处理配置 (`video_processing`)

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `video_width` | int | 1920 | 处理视频宽度（像素） |
| `video_height` | int | 1080 | 处理视频高度（像素） |
| `processing_fps` | int | 25 | 处理帧率（fps，控制处理频率） |

**使用建议：**
- 降低分辨率可以提高处理速度（如1280x720）
- 降低处理帧率可以减少CPU/GPU负载

### 4. 计数模块配置 (`counting_module`)

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enable_counting` | bool | true | 是否启用虚拟检测线计数功能 |
| `show_detection_line` | bool | true | 是否在视频中显示检测线 |
| `detection_line_offset` | int | 324 | 检测线位置偏移（相对于视频中心的像素） |
| `counting_output_path` | string | "./counting_results.txt" | 计数结果输出文件路径 |

**使用建议：**
- 调整 `detection_line_offset` 来改变检测线位置
- 设置 `enable_counting` 为 false 可以禁用计数功能

### 5. 显示配置 (`display`)

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enable_display` | bool | true | 是否启用实时显示窗口 |
| `window_name` | string | "Object Tracking" | 显示窗口名称 |
| `window_width` | int | 800 | 显示窗口宽度 |
| `window_height` | int | 600 | 显示窗口高度 |

**使用建议：**
- 在服务器环境中可以设置 `enable_display` 为 false 来禁用显示
- 调整窗口大小以适应您的显示器分辨率

### 6. 性能优化配置 (`performance`)

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `thread_sleep_ms` | int | 10 | 线程休眠时间（毫秒，控制CPU使用率） |
| `enable_performance_stats` | bool | false | 是否启用性能统计显示 |
| `stats_update_interval` | int | 30 | 性能统计更新间隔（帧数） |

**使用建议：**
- 降低 `thread_sleep_ms` 可以提高响应速度，但会增加CPU使用率
- 启用 `enable_performance_stats` 可以监控系统性能

### 7. 定位上报配置 (`location_report`)

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enable_location_report` | bool | true | 是否启用定位上报功能 |
| `udp_server_ip` | string | "192.168.1.115" | UDP服务器IP地址 |
| `udp_server_port` | int | 12345 | UDP服务器端口 |
| `can_device_type` | int | 2 | CAN设备类型 |
| `can_device_index` | int | 0 | CAN设备索引 |

**使用建议：**
- 根据您的网络环境修改 `udp_server_ip` 和 `udp_server_port`
- 如果不需要定位上报，可以设置 `enable_location_report` 为 false

## 使用方法

1. **修改配置**：编辑 `config.json` 文件中的参数
2. **保存文件**：确保JSON格式正确
3. **运行程序**：直接运行程序，新配置会自动生效
4. **查看日志**：程序启动时会打印加载的配置参数

## 示例配置

参考 `config_example.json` 文件查看完整的配置示例和参数说明。

## 故障排除

1. **配置加载失败**：
   - 检查JSON格式是否正确
   - 确保所有字符串使用双引号
   - 检查是否有多余的逗号

2. **模型加载失败**：
   - 检查 `model_path` 路径是否正确
   - 确保模型文件存在且可读

3. **参数无效**：
   - 检查数值参数是否在有效范围内
   - 置信度和NMS阈值应在0.0-1.0之间
   - 视频尺寸和帧率应为正整数

## 注意事项

- 修改配置后无需重新编译，直接运行程序即可
- 如果某个参数未配置，系统会使用默认值
- 配置文件解析失败时，系统会使用默认配置并继续运行
- 建议在修改重要参数前备份原配置文件
