为了理解locationReport()函数，需要先理解CAN协议中的帧ID（Frame Identifier）。
帧ID（Frame Identifier）是CAN协议中每个数据帧的唯一标识符，它同时承担着地址、优先级和数据类型标识三重功能。
CAN协议中的两种帧格式
CAN总线支持两种帧格式：
标准帧（Standard Frame）：11位ID（0x000-0x7FF）
扩展帧（Extended Frame）：29位ID（0x00000000-0x1FFFFFFF）
这个项目使用的是29位扩展帧格式。
位域功能详解
1>命令字段（CMD）：标识数据的功能类型 ，例如：0x01可能表示GPS数据，0x02示里程数据，0x03表示传感器状态,    定义：BYTE arryData[8];    // 报文数据
2>源地址：在CAN网络中标识发送方和接收方节点
3>目标地址：在CAN网络中标识发送方和接收方节点
4>包序号（Pack）：用于标识同一批次的数据传输，当多个设备同时发送数据时，避免不同批次数据混淆
5>帧序号（Frame No）：标识多帧传输中的帧顺序，支持最多256帧的大数据包传输（8位=2^8=256）
举例：                  
帧1: ID = 0x01685000 (cmd=1, dest=3, src=5, pack=0, frame=0)
帧2: ID = 0x01685001 (cmd=1, dest=3, src=5, pack=0, frame=1)  
帧3: ID = 0x01685002 (cmd=1, dest=3, src=5, pack=0, frame=2)
...
帧6: ID = 0x01685005 (cmd=1, dest=3, src=5, pack=0, frame=5)

系统通过解析这些ID信息，能够：
识别这是GPS命令数据（cmd=1）
确认数据发送给自己（dest=3）
验证数据来源可信（src=5）
确保6帧数据属于同一批次（pack=0）
按正确顺序重组数据（frame=0-5）

每获取到6帧数据，就进行拼接，并计算CRC校验
下面简要介绍CRC16校验：
uint16_t crc = calculateCRC16(combinedData); 这个函数的作用是计算 combinedData 的CRC16校验码。它生成一个16位的校验值
combinedData.push_back(static_cast<uint8_t>(crc & 0xFF)); 这行代码将CRC校验码的低8位（即CRC的低字节）添加到 combinedData 向量的末尾。
0xFF 操作用于提取 crc 的低8位，static_cast<uint8_t> 将结果转换为8位无符号整数（即一个字节）。
combinedData.push_back(static_cast<uint8_t>((crc >> 8) & 0xFF)); 这行代码将CRC校验码的高8位（即CRC的高字节）添加到 combinedData 向量的末尾。

这样做的目的是为了在数据传输或存储后，接收方可以通过重新计算CRC并与接收到的CRC校验码进行比较，以检测数据是否在传输或存储过程中发生了错误。

WinsockSender的作用与定义如下：

WinsockSender初始化成员变量
1.初始化Winsock
2.创建套接字
3.设置目标地址
详细介绍设置目标地址：
1.memset(&serverAddr_, 0, sizeof(serverAddr_));
这行代码使用 memset 函数将 serverAddr_ 结构体的内存全部设置为 0。这是一种常见的初始化方式，确保结构体中的所有字段都被清零，避免出现未定义的值。
2.serverAddr_.sin_family = AF_INET;
这行代码设置 serverAddr_ 结构体中的 sin_family 字段为 AF_INET。AF_INET 表示使用 IPv4 地址族。这是网络编程中指定地址类型的一种方式。
3.serverAddr_.sin_port = htons(port_);
这行代码设置 serverAddr_ 结构体中的 sin_port 字段为端口号。port_ 是一个整数变量，表示服务器的端口号。htons 函数用于将主机字节序（Host Byte Order）转换为网络字节序（Network Byte Order）。网络字节序通常是大端字节序（Big-Endian），而不同的计算机系统可能使用小端字节序（Little-Endian），因此需要进行转换以确保端口号的正确传输。
4.inet_pton(AF_INET, ip_.c_str(), &serverAddr_.sin_addr);
这行代码将字符串形式的 IP 地址转换为二进制形式，并存储在 serverAddr_ 结构体的 sin_addr 字段中。inet_pton 函数的第一个参数是地址族 AF_INET，第二个参数是 IP 地址的字符串表示（通过 ip_.c_str() 获取），第三个参数是存储转换结果的 sin_addr 字段。inet_pton 的全称是 "Internet Protocol network address translation"，用于将点分十进制表示的 IP 地址（如 "192.168.1.1"）转换为网络字节序的二进制形式。
sendData函数的实现
1.地址转换：sockaddr* addr = const_cast<sockaddr*>(reinterpret_cast<const sockaddr*>(&serverAddr_));
const_cast<sockaddr*>：移除 serverAddr_ 的常量性，因为 sendto 函数的参数不是常量指针。
reinterpret_cast<const sockaddr*>：将 serverAddr_ 的类型转换为 const sockaddr*，因为 sendto 函数需要 sockaddr 类型的指针。
2.发送数据：int result = sendto(socket_, reinterpret_cast<const char*>(data.data()), data.size(), 0, addr, sizeof(serverAddr_));
sendto：Winsock API 中的一个函数，用于发送数据到指定的地址。
它需要六个参数
socket_：WinsockSender 类中的一个成员变量，表示已创建的套接字。
reinterpret_cast<const char*>(data.data())：将 std::vector<uint8_t> 中的数据转换为 const char* 类型，因为 sendto 函数的参数类型是 const char*。
data.size()：要发送的数据的大小。
0：标志位，通常设置为 0。
addr：目标地址，即服务器的地址。
sizeof(serverAddr_)：地址结构的大小。
