### 公用数据箱输出信息数据帧格式 (重新排序)

1、串口422通信方式

a)  采用异步数据传输方式

1个起始位，8个数据位，1个停止位，无奇偶校验。

b)
数据传输速率：9600bps。

2、通信帧格式

a)以DLE(10H)、STX(02H)作为帧起始字段，以DLE(10H)、ETX(03H)作为帧结束字段。

b)为避免在信息字段中出现DLE，影响数据的正确接收，数据发送方在发送数据前检查信息字段中是否出现DLE，如果信息字段中出现DLE字符，则在此DLE字符后再加一字节DLE。数据接收方如果连续收到两个DLE字符，表明此DLE是数据信息，而不是控制转义字符，去掉一个DLE即可。基本帧格式见下表：

### 补充帧 (重新排序)

| 序号         | 内 容        | 字节数 |
| ------------ | ------------ | ------ |
| 1            | 帧起始       | 2      |
| **3**  | 信息长度     | 2      |
| **5**  | 源端口代码   | 1      |
| **6**  | 源地址长度   | 1      |
| **7**  | 目的端口代码 | 1      |
| **8**  | 目的地址长度 | 1      |
| **9**  | 业务类型     | 1      |
| **10** | 命令         | 1      |
| **11** | 定位数据     | 2      |
| **13** | 制动状态     | 1      |
| **14** | 工作状态     | 1      |
| **15** | 常用制动限速 | 2      |
| **17** | 车号补充     | 1      |
| **18** | 保留         | 3      |
| **21** | CRC校验      | 2      |
| **23** | 帧结束       | 2      |

计算过程：

新的序号是前一序号加上前一项的字节数得到的 1。例如：

* 帧起始：序号 1，字节数 2
* 信息长度：序号 1 + 2 = 3，字节数 2
* 源端口代码：序号 3 + 2 = 5，字节数 1
* 源地址长度：序号 5 + 1 = 6，字节数 1
  以此类推 2。
