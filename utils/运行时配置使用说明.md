# 目标追踪系统运行时配置使用说明

## 概述

现在您的目标追踪系统已经支持运行时配置！这意味着您可以：

- ✅ **无需重新编译** - 修改参数后直接运行程序即可生效
- ✅ **动态调整** - 可以调整模型路径、置信度、网络参数等所有配置
- ✅ **配置验证** - 自动验证参数有效性，防止无效配置
- ✅ **热重载** - 支持程序运行时重新加载配置（可扩展功能）
- ✅ **配置工具** - 提供专门的工具来管理配置文件

## 快速开始

### 1. 查看当前配置
程序启动时会自动显示加载的配置参数：

```bash
./your_program.exe
```

输出示例：
```
[ObjectTrackingConfig] 配置参数加载成功

========== 目标追踪配置参数 ==========
模型路径: ./models/fil.plan
GPU设备ID: 0
置信度阈值: 0.25
NMS阈值: 0.25
类别数量: 1
视频尺寸: 1920x1080
处理帧率: 25 fps
启用计数: 是
启用显示: 是
UDP服务器: 192.168.1.115:12345
======================================
```

### 2. 修改配置参数

编辑 `config.json` 文件中的 `object_tracking` 节点：

```json
{
  "object_tracking": {
    "yolo_detector": {
      "model_path": "./models/new_model.plan",
      "confidence_threshold": 0.5,
      "nms_threshold": 0.4
    },
    "location_report": {
      "udp_server_ip": "192.168.1.100",
      "udp_server_port": 8888
    }
  }
}
```

### 3. 直接运行程序
修改配置后，直接运行程序，新配置会自动生效：

```bash
./your_program.exe
```

## 常用配置场景

### 场景1：更换检测模型

```json
{
  "object_tracking": {
    "yolo_detector": {
      "model_path": "./models/yolov8s.engine",
      "num_classes": 80,
      "confidence_threshold": 0.5
    }
  }
}
```

### 场景2：调整检测精度

```json
{
  "object_tracking": {
    "yolo_detector": {
      "confidence_threshold": 0.3,  // 降低阈值，检测更多目标
      "nms_threshold": 0.5          // 调整NMS，减少重复检测
    }
  }
}
```

### 场景3：优化性能

```json
{
  "object_tracking": {
    "video_processing": {
      "video_width": 1280,     // 降低分辨率
      "video_height": 720,
      "processing_fps": 15     // 降低处理帧率
    },
    "performance": {
      "thread_sleep_ms": 5,    // 减少休眠时间
      "enable_performance_stats": true
    }
  }
}
```

### 场景4：修改网络配置

```json
{
  "object_tracking": {
    "location_report": {
      "enable_location_report": true,
      "udp_server_ip": "10.0.0.100",
      "udp_server_port": 9999
    }
  }
}
```

### 场景5：禁用显示（服务器模式）

```json
{
  "object_tracking": {
    "display": {
      "enable_display": false  // 在服务器环境中禁用显示窗口
    }
  }
}
```

## 配置工具使用

```bash

mkdir build_config_tool
cd build_config_tool
cmake -f ../CMakeLists_config_tool.txt ..
make  # 或者在Windows上使用 MSBuild
```

### 使用配置工具

```bash
# 显示当前配置
./config_tool -s

# 验证配置文件
./config_tool -v config.json

# 创建示例配置文件
./config_tool -c my_config.json

# 显示帮助
./config_tool -h
```

## 参数详细说明

### YOLO检测器参数

| 参数 | 说明 | 推荐值 |
|------|------|--------|
| `model_path` | 模型文件路径 | 根据实际模型文件位置 |
| `confidence_threshold` | 置信度阈值 | 0.25-0.7（越高越严格） |
| `nms_threshold` | NMS阈值 | 0.25-0.5 |
| `gpu_id` | GPU设备ID | 0（第一块GPU） |

### 追踪器参数

| 参数 | 说明 | 推荐值 |
|------|------|--------|
| `frame_rate` | 视频帧率 | 25-30 |
| `track_buffer` | 追踪缓冲区 | 30-50 |
| `use_reid` | 启用ReID | false（性能优先）|

### 性能优化参数

| 参数 | 说明 | 推荐值 |
|------|------|--------|
| `thread_sleep_ms` | 线程休眠时间 | 5-15ms |
| `processing_fps` | 处理帧率 | 15-30 |
| `video_width/height` | 处理分辨率 | 根据性能需求调整 |

## 故障排除

### 1. 配置加载失败

**问题**: 程序提示"配置加载失败"

**解决方案**:
- 检查JSON格式是否正确（使用JSON验证工具）
- 确保所有字符串使用双引号
- 检查是否有多余的逗号
- 使用配置工具验证：`./config_tool -v config.json`

### 2. 参数验证失败

**问题**: 程序提示"配置参数无效"

**解决方案**:
- 检查数值参数是否在有效范围内
- 置信度和NMS阈值应在0.0-1.0之间
- 视频尺寸和帧率应为正整数
- UDP端口应在1-65535之间

### 3. 模型加载失败

**问题**: 程序提示"找不到模型文件"

**解决方案**:
- 检查模型文件路径是否正确
- 确保模型文件存在且可读
- 使用绝对路径或相对于程序运行目录的路径

### 4. 网络连接失败

**问题**: UDP上报功能无法工作

**解决方案**:
- 检查IP地址和端口配置
- 确保目标服务器可达
- 检查防火墙设置
- 可以暂时禁用上报功能进行测试
